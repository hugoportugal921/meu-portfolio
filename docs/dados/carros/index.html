Como o estudo foi feito

Resumo e problema
A pergunta é se características básicas de um anúncio ajudam a estimar seu preço. O objetivo é demonstrar um fluxo de análise e regressão, sem prometer um preço de venda real.
Dados e tratamento
A amostra reúne os primeiros 1.000 anúncios de uma cópia do conjunto Craigslist Cars & Trucks, de Austin Reese. Foram filtrados preços, anos e quilometragens fora dos limites definidos, valores ausentes essenciais e duplicatas. A condição ausente é tratada como “não informada”.
Metodologia e ferramentas
Python, Pandas e scikit-learn. As categorias são codificadas e as variáveis numéricas padronizadas usando apenas os dados de treino. Foi usada regressão Ridge; 20% dos registros foram separados para teste com divisão reproduzível.

Como experimentar e reproduzir
Escolha fabricante, ano, quilometragem e condição no simulador. Para reproduzir a análise técnica, o código mantido no projeto de origem requer Python 3, Pandas, NumPy e scikit-learn; execute python projects/data-lab/analisar.py com acesso autorizado ao código.
