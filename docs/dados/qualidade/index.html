Como o estudo foi feito

Resumo e problema
O estudo relaciona análise de dados e metalurgia para investigar quais categorias aparecem com maior frequência em uma base de defeitos superficiais. É um estudo independente, sem dados de uma empresa específica.
Dados utilizados
Base Steel Plates Faults, do repositório UCI: 1.941 registros, 27 variáveis e sete classes. A fonte foi disponibilizada sob licença CC BY 4.0 e é atribuída aos seus criadores no rodapé.
Metodologia e ferramentas
Python e Pandas para verificar a estrutura, recuperar as sete classes e agregar contagens e áreas medianas. O painel mostra uma distribuição por frequência e permite comparação entre os tipos de aço A300 e A400.
Principais achados e limites
Aguardando os resultados.
Como experimentar e reproduzir
Escolha um tipo de aço e clique nas categorias. Para reproduzir o processamento técnico, use Python 3, Pandas, NumPy e scikit-learn e, com acesso autorizado ao código, execute python projects/data-lab/analisar.py.
